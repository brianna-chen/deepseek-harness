# @brianna-chen/dsh-client-ui-settings-memory-me

[English](README.md) | 中文

注册为 Web 设置区块的图形化 Memory ME 中心。它支持文件与目录选择、逐项冲突策略、可编辑合并内容、导入前后预览、敏感信息提示、明确确认、进度、验证报告、可执行回滚、历史记录和 Harness 可移植导出。

## 模型体验

无，因为该向导仅存在于浏览器设置界面，不注册面向模型的内容。

#### KV Cache 影响

无。

## 已知限制与后续工作

- 目录选择只导入可识别的记忆 Markdown 文件，不导入任意目录内容。
- 进度按阶段展示，因为 Host 会在一次请求边界提交整个已审阅计划。
