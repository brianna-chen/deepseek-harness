# Agent Note: Memory ME portable coding memory center

Status: implemented

[中文](2026-08-18-memory-me.zh.md) | English

## Problem

Developers moving among Codex, Claude Code, and DeepSeek Harness need to carry portable instructions and skills without copying credentials, chats, logs, caches, or platform-specific state. Migration also needs inspectable conflicts, recovery, and evidence that imported memory reached the Harness runtime.

## Decision

Memory ME 0.2 replaces the original ComeHere prototype. It is a community-scoped installable bundle composed of a Host Remote service, a Web Settings center, and the `memory_me` model tool.

The Host discovers only documented instruction and skill roots. Preview is non-writing and returns source/destination excerpts, line deltas, conflict actions, and line-level secret findings. Conflict policies are skip, safe skill rename, replace with backup, and merge with optional edited content. Import and rollback require explicit confirmation. Every successful write is verified, recorded in history, and represented in an executable rollback manifest. Harness memory can be exported as portable JSON.

Browser directory selection admits only `AGENTS.md`, `CLAUDE.md`, and `SKILL.md`; arbitrary neighboring files are rejected. Size limits, symbolic-link rejection, secret scanning, and destination re-resolution remain Host-owned boundaries.

## Alternatives considered

**Keep ComeHere as a compatibility alias.** Rejected because the feature has not shipped upstream and the requested rename is intentionally complete.

**Silently overwrite conflicts.** Rejected. Replace and merge are explicit preview actions and create backups first.

**Treat a generated report as runtime proof.** Rejected. Deterministic tests load imported instructions through the Harness renderer and imported skills through the filesystem skill registry for Codex and Claude Code separately.

## Consequences

The npm family moves to the `@brianna-chen` scope and version `0.2.0`. The default Web composition mounts Memory ME, and the generated tool catalog includes `memory_me`. The graphical flow remains source, selection, conflict resolution, confirmation, progress, and report, with history, export, verification, and executable rollback available at the appropriate boundaries.
